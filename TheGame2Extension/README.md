# The Game - Browser Extension

A fast-paced neon cyberpunk platformer directly in your browser toolbar popup.

## How to Install and Run in Chrome / Brave / Edge

1. Open your browser and navigate to the extensions page:
   - **Chrome**: `chrome://extensions`
   - **Brave**: `brave://extensions`
   - **Edge**: `edge://extensions`
2. Enable **Developer mode** using the toggle in the top right corner.
3. Click the **"Load unpacked"** button in the top left.
4. Select the extension directory:
   `/home/neo/SoftwareDev/Projects/SelfProjects/TheGame/TheGame2Extension`
5. Click the puzzle icon (Extensions menu) in your browser toolbar and pin **The Game**.
6. Click the extension icon to open and play the game directly in the popup window!

## Features

- **Instant Toolbar Access**: Runs smoothly in an 800x450 popup window when you click the extension icon.
- **Auto-Focus**: Keyboard controls respond immediately without needing an extra click.
- **Popout Mode**: Click the **⤢ Popout** button in the top-left corner to open the game in a standalone floating window for long sessions.
- **100% Offline**: Requires zero network requests or tracking.
- **Full CSP Compliance**: Manifest V3 compliant with externalized scripts (`game.js`).

## Controls

- **Move**: `A` / `D` or Left / Right Arrow keys
- **Jump**: `Space` or `W` or Up Arrow
- **Dash**: `Shift`
- **Wall Jump / Slide**: Push towards a wall and jump
- **Attack / Slashes**: Mouse Click / In direction of aim
- **Reboot / Restart**: `R`
